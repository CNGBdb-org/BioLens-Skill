# GWAS Catalog Guide

The **GWAS Catalog** catalogs **SNP–trait associations** from genome-wide association studies, plus study metadata and EFO trait annotations.

Ask in natural language; include **rsID**, **trait/disease**, **gene**, or **GCST study ID** for best results.

---

## What you can query

| Type | Description |
| ---- | ----------- |
| SNP associations | rsID → traits, p-value, OR, risk allele |
| Trait | Keyword → related GWAS studies |
| Gene | GWAS SNPs mapped to a gene |
| Study | GCST ID → sample size, PubMed, platform |

---

## Example queries

### SNP

- What traits are associated with rs7903146?
- GWAS p-value and OR for rs7903146

### Trait / gene

- GWAS studies for diabetes
- GWAS SNPs in TCF7L2

### Study

- What is study GCST000001?

### Combined

- rs7903146 GWAS hits, gnomAD AF, and ClinVar annotation together
