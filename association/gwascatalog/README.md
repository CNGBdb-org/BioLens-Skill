# GWAS Catalog 使用说明

**GWAS Catalog** 收录全基因组关联研究的 **SNP–性状关联**、研究元数据及 EFO 性状注释。

在聊天框用自然语言提问；写清 **rsID**、**性状/疾病名**、**基因名** 或 **GCST 研究 ID** 更容易命中。

---

## 能查什么

| 类型 | 说明 |
| ---- | ---- |
| SNP 关联 | rsID → 性状、p 值、OR、风险等位基因 |
| 性状 | 关键词 → 相关 GWAS 研究 |
| 基因 | 基因映射的 GWAS SNP |
| 研究 | GCST ID → 样本量、PubMed、平台 |

---

## 示例问法

### SNP

- rs7903146 和什么疾病有关联？
- rs7903146 的 GWAS p 值和 OR 是多少？

### 性状 / 基因

- diabetes 有哪些 GWAS 研究？
- TCF7L2 有哪些 GWAS SNP？

### 研究

- GCST000001 是什么研究？

### 与其他库配合

- rs7903146 的 GWAS 关联、gnomAD 频率和 ClinVar 注释
- TCF7L2 的 GWAS SNP 和 OpenTargets 靶点分数

---

## 数据说明

- 来源：[NHGRI-EBI GWAS Catalog](https://www.ebi.ac.uk/gwas/)
- 关联为统计学证据，需结合功能与临床数据库解读
