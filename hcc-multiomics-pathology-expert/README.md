# HCC 多组学病理专家包

这个 Expert 用来处理肝细胞癌（HCC）的病理和转录组数据。它比较适合做这样一类工作：手里有 H&E/WSI、空间转录组、bulk RNA，或者已经分析过的单细胞结果，希望把数据关系理清楚，做出可追溯的图表和研究结论。它会自己识别空间数据、病理图、bulk RNA 或单细胞文件。只有在确实无法判断时，才会问你：哪些样本来自同一患者、病理图和组学是否来自同一张切片、哪些是肿瘤或癌旁、以及是否有重要的分组信息。


它面向科研分析，不替代病理诊断，也不提供治疗建议。

## 它能帮你做什么

- 把数据整理一遍，确定有哪些样本、属于什么模态、病理和组学是否配得上。
- 做 10x Visium 的基础质控、空间域划分和 HCC/TME 相关程序评分。
- 做 H&E 图像质控、组织区域识别和带坐标的 patch 列表。
- 把同一张切片上的 Visium spot 和 H&E patch 对上，方便回看图像证据。
- 给 bulk RNA 算一组透明的肿瘤、免疫、髓系、基质、血管和缺氧相关分数。
- 把空间、病理和 bulk 的结果整理成带证据、限制和审查状态的报告。
- 遇到单细胞数据时，调用 `scrna-seq-expert` 做 QC、聚类、注释和通讯。

目前的范围只包括 HCC。iCCA、cHCC-CCA 和肝转移最好使用其他 Expert，避免不同癌种混在一起解释。

## 怎么安装

直接对 AI 说（可能需要上传到AI能接触到的目录）：

> 帮我安装hcc-multiomics-pathology-expert这个skill。

## 怎么开始

把专家包上传到平台后，直接说你有什么数据、想回答什么问题即可。

最简单：

> 我有一些肝癌的数据在xx文件夹，帮我分析一下

如果向自定义一些分析：

> 我有 7 例 HCC Visium 数据和对应的 H&E 图片，先帮我看数据质量和配对关系，再比较应答者与非应答者的免疫、基质和缺氧程序。

> 这是一批 HCC bulk RNA counts 和样本表。请检查肿瘤、癌旁、病因和背景肝信息，算通路分数；先不要做生存或疗效预测。

> 这是 HCC 的 H&E PNG 图片。请做图像质控，给我组织区域和可回溯的 patch 坐标；不要把它当作肿瘤分割结果。

如果还没整理样本表，也可以说：

> 这些是我的 HCC 文件，先帮我建立一个 manifest 草案，哪些信息需要我补充请单独列出来。



## 包里的 Skill

| Skill | 用来做什么 |
|---|---|
| `hcc--data-intake-pairing` | 梳理文件、建立 manifest、检查样本配对 |
| `hcc--pathology-qc-evidence` | H&E/WSI 质控、组织区域和 patch 坐标 |
| `hcc--spatial-tme-analysis` | Visium 质控、空间域和 TME 程序 |
| `hcc--scrna-coordination` | 将单细胞任务交给 `scrna-seq-expert` |
| `hcc--bulk-pathway-analysis` | bulk RNA 输入检查和程序评分 |
| `hcc--tumor-ecosystem-interpretation` | 把肿瘤、免疫、血管、基质和背景肝信息放在一起看 |
| `hcc--multimodal-association` | 做配对检查，并把空间结果回溯到病理图像 |
| `hcc--statistical-evidence-review` | 检查混杂、配对错误、数据泄漏和过度解释 |
| `hcc--evidence-reporting` | 生成研究报告和结果索引 |

## 常用提问方式

### 空间转录组和 H&E

> 附件是 HCC Visium 数据和对应 H&E 图片。请先确认哪些是同一患者、同一切片；然后做 spot QC、空间域、免疫/髓系/基质/缺氧程序评分，并把结果链接到 H&E 的 patch 坐标。

### bulk RNA

> 这是 HCC bulk RNA 矩阵和样本信息。请先检查矩阵是 counts 还是标准化数据；再计算 HCC/TME 程序分数，写清楚样本数和可能的混杂因素。

### 单细胞

> 我有 HCC 单细胞 h5ad。请生成交接包，告诉我怎样让 `scrna-seq-expert` 完成 QC、注释和细胞通讯；等它分析完后，哪些结果可以带回这里和空间/病理数据一起看？

### 出报告

> 根据当前运行目录生成一份 HCC 研究报告。请保留数据配对等级、统计审查状态、证据文件位置和限制，不要把探索性结果写成确定结论。

## 使用时需要注意

- Visium 空间域、通路分数和 H&E 组织掩膜都只是研究线索，不等于病理诊断或纯细胞标签。
- 如果要说某一区域是肿瘤相关区域，最好有两类独立证据支持，例如可靠 ROI、CNV、突变、组织来源或经过验证的标签。
- TCGA 的 WSI 和 RNA 通常只能做患者层面的关联；只有明确知道同一组织块或切片来源时，才可以往下做区域层面的解释。
- 单细胞目前是手动交接，不会自动切换到另一个 Expert。
