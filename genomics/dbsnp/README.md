# dbSNP 使用说明

NCBI **dbSNP** 是人类 RefSNP 目录：按 **rsID**、**坐标** 或 **基因** 查 SNP 基本信息、等位基因、功能类型及多来源频率摘要（ExAC、gnomAD、ALFA 等）。默认坐标 **GRCh38**。

在下方聊天框用自然语言提问即可；写清 **rsID**、**基因名** 或 **chr:pos** 更容易命中。

---

## 能查什么

| 类型 | 说明 |
| ---- | ---- |
| 单点 SNP | rsID → 坐标、等位基因、基因、功能类型、MAF 摘要 |
| 坐标反查 | chr:pos → 该位置有哪些 rs 号 |
| 基因变异 | 某基因全部 RefSNP，或按 missense / 罕见 / 常见 / 致病标签筛选 |
| 区域 | 指定区间内的 SNP 列表 |
| 批量 | 一次问多个 rsID |
| 统计 | 某基因 SNV/indel 类型占比 |

---

## 示例问法

### 单点

- 查 rs80357906 的 SNP 信息
- rs80357906 是什么变异？在哪个基因上？
- rs80357906 的功能类型和等位基因是什么？
- 帮我查 rs328、rs80357906 这两个 SNP 的基本信息

### 坐标

- chr17:43057062 是什么 rs 号？
- 17 号染色体 43057062 这个位置有 dbSNP 记录吗？

### 基因

- BRCA1 基因有哪些 dbSNP 变异？
- TP53 有多少 missense 变异？
- BRCA1 有哪些罕见变异（MAF 小于 1%）？
- 给我 TP53 的 dbSNP 变异类型统计

### 区域

- chr17:43057060-43057065 这个区域有哪些 SNP？

### 与 gnomAD / ClinVar 一起查

- rs80357906 是什么变异，人群里常见吗？
- rs80357906 的 dbSNP 信息和 gnomAD 频率一起查
- rs80357906 的 dbSNP、gnomAD 频率和 ClinVar 致病性一起查

---

## 三库怎么配合

| 数据库 | 侧重 |
| ------ | ---- |
| **dbSNP** | 定位、功能注释、多研究频率摘要 |
| **gnomAD** | 精确人群 AF、各族群频率、基因约束 |
| **ClinVar** | 临床致病性、VUS、疾病关联 |

dbSNP 里的 MAF 是各研究汇总；若要 **精确人群频率** 或 **致病性**，可继续问 gnomAD / ClinVar，或直接说「三库一起查」。
