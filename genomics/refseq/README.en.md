# RefSeq Guide

**NCBI RefSeq** provides curated **gene, transcript, and protein** reference sequences with NCBI Gene annotation. Queried via E-utilities; default organism: human.

Ask in natural language; include **gene symbol**, **NM_/NP_ accession**, or **genomic region** for best results.

---

## What you can query

| Type | Description |
| ---- | ----------- |
| Gene | Symbol → RefSeq Gene ID, coordinates, description |
| Transcript | NM_ accession → title, length |
| Protein | NP_ accession → title, length |
| Region | RefSeq genes in an interval |

---

## Example queries

### Gene

- RefSeq Gene ID for BRCA1
- Genomic coordinates of TP53 in RefSeq

### Transcript / protein

- What transcript is NM_007294?
- What protein is NP_009225?

### Region

- RefSeq genes in chr17:43044295-43170245

### Combined

- Compare BRCA1 RefSeq and Ensembl transcripts
- UniProt entry for the protein from NM_007294
