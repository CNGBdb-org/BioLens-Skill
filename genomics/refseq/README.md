# RefSeq 使用说明

**NCBI RefSeq** 提供 curated 的 **基因、转录本、蛋白** 参考序列及 NCBI Gene 注释。通过 E-utilities 查询，默认人类。

在聊天框用自然语言提问；写清 **基因名**、**NM_/NP_ accession** 或 **坐标区域** 更容易命中。

---

## 能查什么

| 类型 | 说明 |
| ---- | ---- |
| 基因 | 基因符号 → RefSeq Gene ID、坐标、描述 |
| 转录本 | NM_ accession → 标题、长度 |
| 蛋白 | NP_ accession → 标题、长度 |
| 区域 | 指定区间内的 RefSeq 基因 |

---

## 示例问法

### 基因

- BRCA1 的 RefSeq Gene ID 是什么？
- TP53 在 RefSeq 里的坐标？

### 转录本 / 蛋白

- NM_007294 是什么转录本？
- NP_009225 对应什么蛋白？

### 区域

- chr17:43044295-43170245 有哪些 RefSeq 基因？

### 与其他库配合

- BRCA1 的 RefSeq 和 Ensembl 转录本对比
- NM_007294 对应蛋白的 UniProt 条目
