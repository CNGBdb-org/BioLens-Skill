# ClinVar 使用说明

NCBI **ClinVar** 收录变异的**临床意义**（致病 / 可能致病 / VUS / 良性等）、评审状态、关联疾病与 OMIM。适用于变异注释、遗传病检索与 VUS 清单。默认坐标 **GRCh38**。

在下方聊天框用自然语言提问即可；写清 **rsID**、**基因名**、**HGVS** 或 **疾病名** 更容易命中。

---

## 能查什么

| 类型 | 说明 |
| ---- | ---- |
| 单点致病性 | rsID / HGVS / ClinVar ID → 临床意义、评审状态、关联疾病 |
| 基因致病谱 | 某基因的致病 / 可能致病变异列表 |
| 基因统计 | 致病、VUS、良性、冲突等各有多少条 |
| VUS / 冲突 | 某基因意义未明变异，或实验室解读不一致的位点 |
| 疾病 | 按疾病或表型关键词查相关致病变异 |
| 区域 | 指定区间内的 ClinVar 变异 |

---

## 示例问法

### 单点致病性

- rs80357906 是致病的吗？
- rs80357906 在 ClinVar 里怎么标注的？
- c.5266dup 这个 BRCA1 变异致病吗？
- ClinVar ID 17677 是什么变异？

### 基因

- 查 BRCA1 的 ClinVar 致病位点
- BRCA1 有多少致病变异，VUS 多吗？
- TP53 基因有哪些意义未明的变异？
- BRCA1 有没有实验室解读不一致的位点？
- 给我 BRCA1 的 ClinVar 变异分类统计

### 疾病 / 表型

- Noonan 综合征有哪些已知致病变异？
- 和 breast 相关的 ClinVar 致病变异有哪些？

### 区域

- chr17:43057060-43057065 这个区域有哪些 ClinVar 变异？

### 与 dbSNP / gnomAD 一起查

- rs80357906 是什么变异，致病吗？
- rs80357906 的 dbSNP、gnomAD 频率和 ClinVar 致病性一起查

---

## 三库怎么配合

| 数据库 | 侧重 |
| ------ | ---- |
| **dbSNP** | 坐标、功能类型、频率摘要 |
| **gnomAD** | 精确人群 AF、基因约束 |
| **ClinVar** | **临床致病性、VUS、疾病关联** |

ClinVar 结果中的 **VUS（意义未明）** 不可表述为致病；存在 **解读冲突** 时需结合其他证据重评。
