# UniProt 使用说明

**UniProt** 收录蛋白质序列与 **功能注释**、亚细胞定位、通路及 **疾病关联**。默认查询人类蛋白。

在聊天框用自然语言提问；写清 **基因名**、**UniProt accession** 或 **疾病名** 更容易命中。

---

## 能查什么

| 类型 | 说明 |
| ---- | ---- |
| 基因→蛋白 | 某基因对应的人类蛋白条目 |
| 蛋白详情 | accession → 名称、长度、交叉引用 |
| 功能 | 生物学功能、定位、催化活性、通路 |
| 疾病 | 与疾病关键词相关的蛋白 |

---

## 示例问法

### 基因 / 蛋白

- BRCA1 的 UniProt accession 是什么？
- P38398 是什么蛋白？
- TP53 编码的蛋白有多长？

### 功能

- TP53 蛋白的主要功能是什么？
- BRCA1 的定位和通路注释？

### 疾病

- 和 breast cancer 相关的 UniProt 蛋白有哪些？

### 与其他库配合

- BRCA1 的 Ensembl ID 和 UniProt 条目
- TP53 的 UniProt 功能注释和 GO 术语
