# UniProt Guide

**UniProt** catalogs protein sequences with **functional annotation**, subcellular location, pathways, and **disease associations**. Default query scope: human proteins.

Ask in natural language; include **gene**, **UniProt accession**, or **disease keyword** for best results.

---

## What you can query

| Type | Description |
| ---- | ----------- |
| Gene → protein | Human protein entries for a gene |
| Protein detail | Accession → name, length, cross-refs |
| Function | Biological role, location, pathways |
| Disease | Proteins linked to a disease keyword |

---

## Example queries

### Gene / protein

- UniProt accession for BRCA1
- What protein is P38398?
- Length of the TP53 protein

### Function

- Main function of TP53 protein
- Subcellular location and pathways for BRCA1

### Disease

- UniProt proteins associated with breast cancer

### Combined

- BRCA1 Ensembl ID and UniProt entry together
- TP53 UniProt function and GO terms
